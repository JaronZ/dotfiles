# Dotfiles

Dotfiles for my Ubuntu installation used in the RDW Self-Driving Challenge.

These dotfiles are focussed on python, C++, ROS2, and Autoware. It also contains my preferred editors and shells (vim, code, zsh, bash).

## Requirements

- git
- stow

```bash
sudo apt install git stow
```

## Installation

```bash
git clone git@github.com:JaronZ/dotfiles.git
cd dotfiles
```

```bash
stow .
```
